# BackBouncing
An idea I had for Hack Club Haven, but wasn't able to bank on it since I was an org. I need to learn some more tricks and stuff to make it less jank, but it still works as a prototype for now. Has basic platformer controls (A, D, space,) but you can also hold F to freeze time while you decide what direction to bounce away from. The game definitely could've had a lot better level design, but tbh I was just trying to get this done, it was supposed to be done way earlier, lol.
try the game here: https://blowupthenoobs.itch.io/backbouncing
